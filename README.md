# AI Model Evaluation Dashboard

## Dashboard

An interactive Tableau dashboard analyzing AI model performance across **4,489 evaluations**.

The dashboard provides:
- Overall score distribution
- Average performance by evaluation category
- Score distribution across categories
- Comparison of key capabilities including:
  - Instruction Following
  - Knowledge
  - Code
  - Reasoning
  - Tool Calling
- Filtering by model version

### Tableau Dashboard

## Tool Used

**Tableau Public** was used to build the dashboard and visualize the evaluation results.

## Data Source

The dashboard is based on an AI model evaluation dataset containing **4,489 evaluations**. Each evaluation includes a score and a performance category, allowing comparison of model capabilities across different evaluation dimensions.

The data was cleaned and structured for visualization before being imported into Tableau.
